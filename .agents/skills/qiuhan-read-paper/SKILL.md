# 邱寒读论文

以“阅读目的—核心逻辑—方法机制—证据—研究价值”指导具体任务。名称用于识别课程方法，不扮演老师本人；第1–3讲为主干，吸收后续研究评价内容，保留共同授课与来源归属。

## 接到任务后

1. 确认已见材料范围：题目、版本、正文、附录、代码分别有什么。用户已给目标就直接开始；目标未明时默认先理解全篇，先读 Introduction 与 Methods，随后按论证需要补摘要、相关工作、实验和结尾。不能把只见摘要写成读过全文。
2. 阅读 [阅读流程](references/reading-workflow.md)，按目标选择深度：找背景/引用可定向读；复现须看实现与参数；评价须看相关研究与实验条件；多篇比较先统一比较问题与设置。
3. 默认完成分析并在聊天交付。用户要“带我学/逐章读”才启用教学模式；已有进度按原始目录继续，不重新讲全篇。只在用户要求保存、归档或任务本身需要时写文件。

## 必须真正执行的五个认知动作

### 1. 用自己的话还原主张

给一句话概括，包含“在什么问题/条件下，用什么核心思路，解决什么具体局限”；继而连起背景→具体挑战→已有工作及不足→核心 idea→设计→验证→结论边界。A–H 是识别信息功能的镜片，不要求原文按八章排列。先说明作者主张，再说明你是否被证据说服。

### 2. 从结构图走到可追踪的机制

先给全局流程；沿一个连续案例说明每阶段输入从哪里来、组件做什么、中间产物、下游消费者和失败条件。区分设计、实现与讲解用简化。对关键组件追问“目标—挑战—思路—操作—分析”，用原图/正文/公式核对，不能以复述模块名代替理解。自建 toy example 标明教学构造及简化条件，不能当一般有效性的证据。

需要方法、公式、复现、实验分析时加载 [机制与证据](references/methods-and-evaluation.md)。核查课程案例原图时先看 [来源定位与公开范围](references/source-index.md)；本包不附课件截图，无法取得原图时明确范围，不以 AI 摘要补足。复现任务还要给步骤、输入/环境/参数来源、验证标准与缺失的决定信息；材料不足时完成复现准备，不虚构可运行实现。

### 3. 让实验回答明确问题

先查数据代表性、划分、环境、实现层次、参数、指标与基线公平性，再区分整体效果、组件/微基准、消融和案例。逐项写“主张—实际证据位置—可支持范围—缺口”，不把好看的总结果当组件归因；缺失实验只能标缺失，不能推断作者做过。理论/综述按其证明或综合证据方式适配，不硬塞系统实验模板。

### 4. 在背景中判断价值

读懂后再判断问题重要性、idea 新意、相关研究位置、验证可信度、成本与实际适用范围。复杂不自动高级，简单不自动增量；引文/会场/下载量是带时间和语境的线索。局限→机会之间还要检验重要性、可行性与相关工作，不能直接当选题。

评审、价值判断和多篇对比加载 [判断与评审](references/judgment-and-review.md)。对本课程正式 review 先看下述课程边界。

### 5. 让结果可使用

完整分析通常给：一句话→问题与论证链→全局方法及连续例子→证据与边界→价值判断/未解问题。定向任务只交付相关部分。比较论文按共同维度给差异及条件，拒绝无依据总排名。问题写成“观察/证据位置—影响—可回答问题”，把事实错误与可选建议分开。

## 教学模式

先用简短说明确认当前相关基础，可从用户现有表述判断，不根据学历/旧卡点固定能力。先全局后局部；每步用具体输入输出讲清。轻量复述题只帮助校正误解，不作为前进门槛。用户要求继续、总结或换论文时直接调整；保留当前版本、章节、已讲点与待解疑问。

## 关键边界与来源

- 论文事实以当前实际原文为准；课程例子是教学版本，不是该领域的最新事实。当前引用量、最新方法、会场规则等须当次核验。
- 跨领域时按任务补查相应的一手统计、实验或报告准则，只加载影响当前判断的专业细则，不把课程框架扩成无关清单。
- 看不到全文、关键图表或实验时明确范围，并完成现有材料能支持的分析；不得填补结果、引用和“首次”主张。
- 课程转写未经音频核听；ASR 的否定、数量、术语与日期歧义不能硬化为规则。首次遇到来源争议读 [证据与边界](references/evidence-and-boundaries.md)。
- 本课程 L04-P029 明确禁止 AI-generated review；处理该课正式评审时提供独立阅读与证据核查的教学支持，不生成替代提交稿。普通研究分析不套用课程限制。完整课务口径见 [课程作业分支](references/course-assignment.md)。
- 课程方法依据可用“L03-P024”等定位；实际分析中的证据引用应定位正在读的论文页/节/图，不能只引用课程。
