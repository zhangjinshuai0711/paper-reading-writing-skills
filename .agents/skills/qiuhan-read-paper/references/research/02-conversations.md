# 口述补充：读论文的判断过程

本文件属于女娲蒸馏的“长对话/课堂即兴讲解”维度。只根据本地课堂材料整理，不建立外部人物画像。所有时间是原始自动转写中的定位，**未经 MP3 内容核听**；下表是释义，不是准确逐字引语。说话人编号和识别人名不用于确定教师身份。课件直接规则优先，口述提供理由与条件；语音独有且含混的细节仍待核。公开版只保留下述释义和时间索引，完整转写不随包分发。

## 全量来源及角色

第2讲 [自动转写](../source-index.md) 用于逻辑主线和背景阅读；第3讲 [自动转写](../source-index.md) 是方法、实验、评价主干；第4讲 [自动转写](../source-index.md) 回顾评价并切换作者视角；第5、6讲的写作讲解用于反向检查论文组织及证据表达。第1讲无录音，依课件及课堂笔记。本文件以五份完整文字材料建立口述索引；文字通读不表示每个词都被纠正，逐份覆盖以整体验证记录为准。

## 逻辑先行，缺知识再补

| 定位 | 口述所补充的思路 | 转成操作时保留的条件 |
|---|---|---|
| L02 开头回顾、13–19分钟附近（该长段缺密集时间戳） | 背景→具体小问题→现有方法不适用→一句话idea→设计→实验 | 只在确有原文依据时填节点；不能靠“论文通常如此”补出作者没说的逻辑 |
| L02 中段 Rowhammer 讲解，约19–30分钟，段内定位不精确 | 先说明物理/虚拟内存等最少背景；做本方向要追防御类别和后续进展；仅获取大意不必追每个词 | 补知识的深度由阅读目标决定，严谨技术解释须核论文，不能把ASR中的错误硬件解释当事实 |
| L02 52:36–52:52 | 有目的地追必要文献，而非无限递归 | 三五篇/最多十篇是经验口述，不是配额 |
| L02 53:08–57:51 | 背景定义→分类→代表方法，Related Work 看做到哪里和局限 | 分类要有真实区别，不能把任意论文分成固定三类 |
| L03 00:45–07:36 | 从摘要引言建根节点，按章节和组件逐层建树 | 目录是线索，节点功能比章号重要 |

## 深入方法时问什么

| 定位 | 口述补充 | 阅读动作 |
|---|---|---|
| L03 10:22–20:25 | 一个模块也有目标、挑战、思路、实现、优化；数据类型分支共享结构，重点展开差异 | 先画组件关系，再分支；不逐段重复相同解释 |
| L03 25:15–27:56 | 设计既要说 how 也要说 why；问组件有必要吗，能否更简单，好处与缺点是什么 | 不把“复杂”“公式多”直接等同贡献；有些优势属于解释与质性分析，不强求单一分数 |
| L03 29:41–31:57 | toy example 和流程图可像断点调试一样跟进方法 | 示例是理解入口，再查真实约束；课件L03-P014备注提醒可能不完整或误导 |
| L06 54:44–01:00:34 | Overview模块对应Design章节；数学需讲建模、转换、分析/证明，不应藏掉关键难点 | 检查论文的概览承诺是否被详细设计兑现，必要推导能否复原 |

## 实验先审环境，再解释分数

| 定位 | 口述补充 | 阅读动作 |
|---|---|---|
| L03 32:25–35:22 | 几十倍提升可能受仿真/生产环境、基线等条件影响 | 将提升数字和条件一起记录，不独立摘取分数 |
| L03 35:22–39:27 | 端到端、组件分析、应用案例分别回答整体效用、必要性、实际用途 | 实验分工明确；案例不代替普遍有效性 |
| L03 39:54–44:23 | 正文设置短，可能详见附录 | 先找附录再批评遗漏；未获取附录标“未见”，不说作者没写 |
| L03 50:23–58:30 | 数据要真实、有代表性和多样性；规模不等于多样性；安全数据有隐私、偏差、知情同意与披露问题 | 检查主张场景是否被覆盖；按领域启用伦理问题，不凭课程推断论文实际违规 |
| L03 59:38–01:01:31 | 开源受商业与伦理约束；不开源不等于假，公开也不保证完整复现 | 评价复现可行性和可信证据，避免以代码开关定真假 |
| L03 01:01:31–01:06:44 | 仿真、原型、生产实现不同；工程约束会影响设计是否实现 | 拆开设计、真实实现与验证层次；列未实现功能 |
| L03 01:07:21–01:10:43 | 参数、最新基线、公平对比、指标覆盖影响结论 | 某一旧基线领先不等于当前SOTA；核适用条件和可获得时间 |
| L03 01:11:54–01:15:46 | 观察→解释，实验也发现新问题；消融看必要性，lessons比孤立数字重要 | 分开数据观察、作者解释、自己的推断，保留替代解释 |

## 从理解转到评价

- L03 01:17:37–01:21:14：讨论局限、结论的broader insight，回看核心贡献与没讲什么；缺失不自动等于隐藏。
- L03 01:21:53–01:25:16：读懂与判好坏是两种工作。顶会不保证好，新方向可能不成熟；不能把成熟度当唯一价值。期间的出版史口述未独立核实，只保留评价原则。
- L03 01:29:29–01:34:20：旧idea可能随条件成熟而实现；引用和下载指标有局限且可能被操纵。
- L04 00:00–24:13：问题和解法双维评价，重要问题、intellectual nugget、可信证据、假设变化后还成立吗；工业界暂不接受是引用演讲中的启发，不是“被行业反对就好”的规则。
- L04 25:49–35:20：论文为外部读者沟通科学思想，反向检查 what/why/how，而不是被代码量、工作过程或修辞带走。

## 不使用的口述

不将未核实的人际故事、猜测评审身份、报复性表达、训练成本、人名、录取率估计和行业未来预测转为可执行方法。第2讲“固定三个小节”保留为个人训练偏好；课程同时强调不存在普遍硬规则。第4讲AI与课程评审须按正式课程分支处理，不能从教师使用AI读材料的口述推出正式作业的无限许可。
