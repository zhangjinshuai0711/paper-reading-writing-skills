# 邱寒读论文：调用方式与验证记录

机器调用名为`$qiuhan-read-paper`；显示名称为“邱寒读论文”。安装位置是当前课程项目`.agents/skills/qiuhan-read-paper/`。公开分享版保留方法、案例与来源定位，不附完整课件、转写和截图。日常使用不依赖原始课程目录；核验课程原述须自行合法取得相应资料。

## 调用示例

```text
请用 $qiuhan-read-paper 分析这篇论文，先讲清问题和完整流程，再沿一个例子解释方法输入输出，最后核查实验支持了什么。
请用 $qiuhan-read-paper 比较这三篇论文在同一任务下的假设、机制、代价与证据，标出不可直接比较的条件。
用 $qiuhan-read-paper 带我读这篇论文。先确认我当前卡住的概念，再按原目录继续；不要每次重新讲全篇。
```

默认直接完成分析，在聊天交付。只给摘要时仍可提取已见逻辑与问题，不能作全文评价。复现准备会列出步骤与缺失决定信息，缺全文时不编可执行实现。

## 本轮行为验证

由独立答题角色实际加载Skill回答课程DeepAID、未入示例的植物耐旱证据、全文缺失的理论复现三题；另补 toy example 和 MobiCom 评价条件两项已知规则。另一角色评审来源与行为。以下为本地完整版第一轮历史答题与独立评审，核心行为均通过；公开分享版未重跑这些题目，具体证据与未测范围见下列记录。

- [实际答卷](validation/reading-answers.md)：题面、实际回答、读取资料及教学风格展示。
- [独立评审](validation/reading-review.md)：独立评审、偏差与针对性修改记录。

- [精炼处置](validation/refinement.md)：独立建议的实际采纳与未测范围。
- [结构检查](validation/structural-validation.json)：公开分享版文件可用性与发布范围快照。

## 三种状态分别报告

1. **文件已生成**：入口、元数据、方法与案例、来源和底稿已存在；公开版命名、元数据、包内链接与排除原始材料检查通过，见结构记录。
2. **行为结果**：仅在实际回答与独立评审完成后说明具体通过项与不足。构造题是有限场景验证，不是大规模盲测，更不能证明达到老师本人水平。
3. **用户实际使用认可**：尚待用户在真实论文与稿件中使用后反馈，不替用户验收。

材料覆盖见 [逐页记录](coverage.md)；来源层级、第一讲无录音和MP3未核听限制见 [来源索引](source-index.md) 与 [音频记录](audio-verification.md)。不把结构合法、文件很多或内容较长当作质量证明。
