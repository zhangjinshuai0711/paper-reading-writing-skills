## 2. 从材料中提炼的六个核心课程框架

### 框架 A：读者导向的信息传递

**来源**：L04-P018–P020、P030–P036；L05-P004–P005；L06-P059–P066。

研究作者掌握全部过程，读者未必有相同背景和动机。因此作者必须明确要传达的中心信息，以读者当下需要知道的问题安排顺序，并提供必要解释。简洁不是词数越少越好，而是让每一个词、图和段落有传递任务。

**执行化**：接任务先确定读者、目的和中心信息；每节明确“读到这里应理解什么”；删去不服务主线的信息；必要背景不能以追求短小为由删掉。图文互补，图本身不新增理解障碍。

**边界**：不同读者需要不同解释深度；“读者没看懂则作者需要修改”是促使作者承担沟通责任的原则，不意味着任何专业细节都能脱离训练立刻理解。

### 框架 B：四个说服任务

**来源**：L04-P031–P033；L05-P027–P044。

论文要让读者看到问题重要、问题确实困难、本文已经解决到什么程度、贡献与已有工作有何区别。四者相互制约：问题越重要不代表方案已成功；结果好看不代表问题有价值；标榜新颖不等于证明差异。

**执行化**：用四项问题检查摘要与引言，再回指方法和证据。对“重要”找后果，对“难”找机制，对“解决”找验证，对“新”找最近相关工作。不给每项强制分节，也不把所有论文变成系统论文。

**边界**：测量、经验、复现、综述等类型以自己的发现和证据承担说服任务，不虚构系统设计来适配模板。

### 框架 C：问题—挑战—设计—证据对应

**来源**：L05-P033–P043；L06-P027–P046；L05 转写 01:07:43–01:08:06（未核听）。

从使用需求导出目标和挑战，再解释设计如何应对，最后用相应实验或证明检验。概览、详细设计和评估不是相互独立的材料堆，而是同一论证的逐层展开。

**执行化**：建立对应表，找无目标设计、未解决挑战和无证据主张；组件命名与章节路线一致；设计与实现存在差异时解释，不把理想设计当原型事实。

**边界**：对应是逻辑关系，不要求数量一一相等；一个设计可处理多个挑战，需说明理由。表格是本次整理工具，不是老师必须使用的固定文档。

### 框架 D：从散料到提纲再到成稿的迭代

**来源**：L05-P006–P012、P018、P031。

先把想法写出来，再按主题和逻辑组织，最后扩展与修订。写作可以帮助发现研究漏洞；不同写作顺序有优缺点，不能等到最后只靠语言修改，也不能在研究未完成时强行锁定漂亮故事。

**执行化**：捕获事实 → 主题分组 → 段落问题与首句 → 扩展正文 → 多轮检查；主张稳定时自上而下，材料未收敛时先写可靠技术与结果再重组；朗读、隔时阅读和外部试读用于不同缺陷。

**边界**：迭代不等于无限修辞；研究缺口需要补研究或缩小主张。作者应接纳反馈，但不能无判断接受所有建议。

### 框架 E：详细技术中的嵌套小故事

**来源**：L06-P028–P033、P045–P046。

全篇有大故事，每个组件与实验也有局部逻辑：组件从目标与想法到挑战、机制和分析；实验从设置到观察、解释和意义。这样读者知道细节为什么存在。

**执行化**：组件写目标/理由/操作/分析，实验写目的与设置/直接现象/解释与边界。关键数学先讲作用再推导，图表先说明读法再分析洞见。

**边界**：不是强制段落中出现六个小标题，也不能为叙事顺滑隐去难懂但必要的推理。因果解释需要证据，推测不写成已证明原因。

### 框架 F：研究真实性约束下的写作质量

**来源**：L04-P038；L05-P029、P044；L06-P034–P043、P049–P057。

表达帮助好研究被理解，却不能救回不存在或不可靠的研究。设计、原型、生产部署、实验观察、理论结论和未来计划必须区分；局限要承认并解释影响；引用必须真实正确。

**执行化**：事实状态底板；缺证据仍写能写部分；摘要和结论不升级证据；必要内容留正文；逐项保护公式、数字、引用与范围词。

**边界**：事实底板和交付状态属于本次工程化整理；不能声称课件已经给出一套完整统计学、伦理审查、署名或审稿回复规范。

这些框架在不同章节和案例中重复出现，并能指导新材料的处理；它们大多属于科研沟通的共同方法，不能仅凭本课程证明其个人排他性。因此按女娲的排他性检验降格为课程框架与条件化启发式，不宣称独家人格模型。

## 3. 六个蒸馏维度的观察

### 教学框架

课程先从阅读建立论文整体结构与评价意识，再转到写作。第四讲连接“何为好研究”与“为何、为谁、怎样写”；第五讲从过程推进到标题、摘要、引言等前部；第六讲展开正文和表达元素。写作不是英语润色课的附属，而是研究信息与论证的组织。【L04-P003–P018；L05-P002–P018；L06-P002–P004】

### 课堂对话与读者视角

转写反复围绕“你怎么讲”“读者看到了什么”“这有什么意义”等问题展开。可提炼为用读者问题驱动修订，而不是模仿口头停顿、转写错词和反复。第四讲 01:14:36–01:28:20，及第六讲 01:13:41–01:16:50 可定位相关语境；均为未核听自动转写。

### 表达方式

清楚的 what/why/how、先给大图景、首句形成提纲、例子辅助直觉、少用自夸与“显然”等表达，是材料中反复出现的共性。【L04-P018、P033–P036；L05-P031；L06-P101–P104】这些也是学术写作的普遍做法，不能包装成某人的独有语言指纹。

### 比较与反例

标题长短对照说明信息取舍；DeepAID 摘要与引言说明抽象结构如何落到真实论文；图表好坏和多轮版本说明表达需迭代；长句修改说明简洁同时保留条件；Paxos 叙事提醒表达形式不能挡住核心。【L05-P020、P024–P026、P033–P047；L06-P067–P084、P101；L04-P039–P041】纯图片页的具体视觉变化仍须图像证据。

### 判断与修改案例

最稳定的判断不是“该句好不好听”，而是“它是否真实、是否解决读者此时的问题、与后文是否对应、结果能否支持主张”。由此将修改顺序排成研究证据→故事结构→段落→语言版式，属本次对教学优先级的执行整理。【L04-P030–P038；L06-P035、P045–P050】

### 课程递进

背景和相关工作在第五、六讲重现，实验要素又承接阅读课。重复说明同一问题可从“读者怎样判断”转成“作者怎样交代”，不必在技能中重复维护两套相同规则。入口按任务导航，详册保留各章依据。

没有材料支撑的私人经历、外部评价、完整思想谱系和个人风格形成史不填。被引用的研究者和书目仅证明课件介绍过，不自动构成老师的师承或全部方法来源。

## 4. 十条条件化启发式

| 条件 | 建议动作 | 来源与限制 |
|---|---|---|
| 中心主张与证据稳定 | 自上而下写有利于统一故事 | L05-P018，不是唯一正确顺序 |
| 研究仍收敛 | 先写可靠技术/结果，再重组前部 | L05-P018，防流水账 |
| 相关差异无需技术细节 | 可提前写相关工作 | L05-P059 |
| 差异需要技术铺垫 | 可后置相关工作，引言先定位 | L05-P059，不据位置推断创新 |
| 背景概念后文不用 | 删除或压缩 | L05-P050；宽读者场景需必要台阶 |
| 某组件不能映射实现 | 明确设计/实现差异及影响 | L06-P034–P036 |
| 图中现象可直接观察 | 先客观陈述，再给解释 | L06-P045–P046；解释因果需证据 |
| 局限推翻中心目标 | 补方法/证据或缩小主张 | L06-P049–P050，不能靠修辞化解 |
| 必要证据决定读者判断 | 放正文而非只放附录 | L06-P057，仍核对实际投稿政策 |
| 只改语言但范围词改变 | 视为实质变更，回查并说明 | L04-P018、L05-P044；保真检查为整理 |

## 5. 冲突、歧义及保守解释

1. **写作帮助研究 vs 研究先于写作**：L04-P038 强调好写作救不了坏研究，L05-P009–P010 鼓励早写。解释为早写帮助发现洞，不把未完成研究包装成已完成；两者可以并存。
2. **简洁 vs 自含**：L04-P034–P036 共同要求删冗余并保留理解所必需信息，不能一味缩短。
3. **吸引力 vs 客观性**：L05-P019、P044 要吸引人，L04-P018、L06-P102 要客观；通过选择有意义的问题、机制和证据实现吸引力，不使用夸大词。
4. **贡献页的 “Be subjective”**：与全课客观原则存在字面冲突，不按孤立词组制定夸大规则；采用 clear/attractive/true 的明确要求。
5. **相关工作位置与自信**：转写有疑似颠倒/错词，按 L05-P059、L06-P014 的可理解性理由处理，不制造以位置判断质量的启发式。
6. **摘要“似懂非懂”口述**：L05 转写 01:04:49 仅支持理解核心思路而不需要所有细节，不指令故意模糊。
7. **未来工作“标记方向”**：可以公开真实研究方向，但不能虚构初步结果或抢占未完成事实。
8. **具体长度与数目**：150–200 词、三至五项贡献、引言一至一页半、全篇约四分之一见技术贡献、讨论篇幅、图位置等是场景化建议，不是通用硬约束。
9. **“previous work” 与 displayed equation**：词语和排版偏好不能升格成语法/数学正确性判据。
10. **自动转写错词**：如 L06 局限讨论把 limitations 反复转为“评审/提审”等，依清晰课件与上下文只概括含义，不保留为老师原话。

## 6. 覆盖边界与尚不能宣称的能力

已形成详册、章节指南、图表/公式/语言手册和正反案例。它们能支持材料组织、起草、修订与检查，但文件完整不等于任务行为已经通过独立验证，更不等于达到老师本人能力。

课程未系统展开全部论文体裁、所有学科统计设计、所有期刊政策、研究伦理细则、投稿信与审稿回复；遇到这些任务应使用实际规范和可靠资料，不将通用补充冒称本课程专属方法。写作入口可以跨领域迁移逻辑，专业真实性仍需领域证据。

本组的教学例子与真实课例已分别标识。行为测试应另用未直接写入例子的输入，检查缺实验不编造、相关工作可分类、设计与实现差异被发现、图注有对象条件、保留语言范围词，并由独立评审判定；不把这里的示例输出当作盲测结果。
