# 元杰写论文：六维蒸馏底稿导航

本目录记录如何从课程证据走到可执行框架。日常任务先按`SKILL.md`运行；只有查依据、处理冲突或更新方法时再读本目录，避免重复加载全部材料。

| 维度 | 文件 | 用途 |
|---|---|---|
| 教学框架/系统材料 | [主分析](01-writing-analysis.md) | 课程框架、来源证据、操作方式及失效条件 |
| 长对话/课堂即兴 | [课堂口述](02-conversations.md) | 完整转写的关键时间定位、课堂理由和未核听边界 |
| 表达方式 | [表达DNA](03-expression-dna.md) | 先全局后局部、连续例子、反问与观察/解释分层 |
| 比较/反例/张力 | [条件张力](04-tensions-and-counterexamples.md) | 简洁与完整、早写与后定、故事与真实性等条件判断 |
| 判断/修改案例 | [真实教学判断](05-decisions.md) | 触发情境、老师如何处理、运行化复用及边界 |
| 课程递进 | [六讲递进](06-course-progression.md) | 从读者理解到作者表达的转换与交叉内容归属 |

这里提炼的是课程阅读/写作方法。跨案例重复与生成力有证据，不足以证明这些通用科研方法属于某人的独家模型。个人经历、外界人物评价、私人价值排序和完整思想谱系没有充分资料，明确留空；不为凑人物模板补写。

回查原始依据用 [来源索引](../source-index.md) 和 [逐页覆盖](../coverage.md)；具体限制见 [证据边界](../evidence-and-boundaries.md)。实际任务结果见 [使用与验证](../usage-and-validation.md)。
