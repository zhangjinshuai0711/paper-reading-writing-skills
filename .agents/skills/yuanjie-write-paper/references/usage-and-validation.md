# 元杰写论文：调用方式与验证记录

机器调用名为`$yuanjie-write-paper`；显示名称为“元杰写论文”。安装位置是当前课程项目`.agents/skills/yuanjie-write-paper/`。公开分享版保留方法、案例与来源定位，不附完整课件、转写和截图。日常使用不依赖原始课程目录；核验课程原述须自行合法取得相应资料。

## 调用示例

```text
请用 $yuanjie-write-paper 把这些真实研究记录组织成论文主线、章节提纲和摘要；结果尚未完成的部分明确标记。
请用 $yuanjie-write-paper 修改这段引言和相关工作，解释结构改动，保留所有技术含义、公式、数字与条件。
用 $yuanjie-write-paper 检查这张图和图注是否自明，再写设置—观察—解释的结果段，不能补造显著性。
```

默认直接交付本轮提纲、草稿或修改稿；“带我写”才逐步讲选择。只润色时不擅自改研究结构。本课程正式评审的AI禁令与投稿CFP限制须按课程分支识别。

## 本轮行为验证

由独立答题角色实际加载Skill处理无结果散记、相关工作流水账/设计实现矛盾、图注数值与统计边界、英文保真润色四题；另一角色评审。以下为本地完整版第一轮历史答题与独立评审，核心行为均通过；公开分享版未重跑这些题目，具体证据与未测范围见下列记录。

- [实际答卷](validation/writing-answers.md)：题面、实际回答、读取资料及教学风格展示。
- [独立评审](validation/writing-review.md)：独立评审、偏差与针对性修改记录。

- [精炼处置](validation/refinement.md)：独立建议的实际采纳与未测范围。
- [结构检查](validation/structural-validation.json)：公开分享版文件可用性与发布范围快照。

## 三种状态分别报告

1. **文件已生成**：入口、元数据、方法与案例、来源和底稿已存在；公开版命名、元数据、包内链接与排除原始材料检查通过，见结构记录。
2. **行为结果**：仅在实际回答与独立评审完成后说明具体通过项与不足。构造题是有限场景验证，不是大规模盲测，更不能证明达到老师本人水平。
3. **用户实际使用认可**：尚待用户在真实论文与稿件中使用后反馈，不替用户验收。

材料覆盖见 [逐页记录](coverage.md)；来源层级、第一讲无录音和MP3未核听限制见 [来源索引](source-index.md) 与 [音频记录](audio-verification.md)。不把结构合法、文件很多或内容较长当作质量证明。
