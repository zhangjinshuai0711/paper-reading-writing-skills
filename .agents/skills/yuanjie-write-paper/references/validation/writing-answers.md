## W1：散记、无结果与夸大愿望

### 题面

便携水质传感器希望节省电池，按信号波动调整采样频率；目前只写了 Python 离线模拟，没有硬件、没有实验结果；计划比较固定采样。作者希望声称“首次、零损失、提升70%”。要求给主线、提纲、摘要草稿及缺口，不编造结果。

### 实际回答

现在可以把它写成一项待验证的自适应采样方案。现有材料支持“提出了思路并编写了离线模拟程序”，还不能支持节省了多少电量、是否无损，更不能证明首次。

**一句话主线**：针对便携水质监测中的采样开销，研究利用信号波动调整采样频率的方案，考察它能否在降低采样次数的同时保留任务所需的信息；目前处于离线模拟准备阶段，效果与硬件能耗仍待验证。

“采样次数更少”和“电池更耐用”之间还隔着能耗模型与硬件行为；“波动小”也不保证没有短暂但重要的事件。论文应把这两个关系作为验证问题，而不是默认成立。

| 信息 | 当前状态 | 可写到什么程度 |
|---|---|---|
| 按信号波动调整频率 | 已有方案思路 | 描述设计目标与已知机制，不补未提供的阈值或公式 |
| Python 离线模拟 | 程序已编写 | 写明实现层次；未提供运行结果，不能称已验证 |
| 固定采样比较 | 未来计划 | 写成比较设计，不写成胜过基线 |
| 节省电池 | 研究目标 | 需能耗定义、模型或实测 |
| 零损失、70%提升 | 尚无证据 | 从当前贡献与结果中移除 |
| 首次 | 未核验 | 当前不使用，后续按相关工作检索界定差异 |

**建议标题**：“面向便携水质监测的基于信号波动的自适应采样方案”。这个标题交代对象和思路，未预告尚不存在的性能结论。

**提纲**：

1. 引言：便携监测为何关心采样开销；本文考察的具体权衡；当前工作的范围和阶段。
2. 问题与必要背景：输入信号、采样动作、最终监测任务、预算及可接受误差的定义。未知部分明确待定。
3. 相关工作：围绕固定采样、自适应采样及能耗/信息保留评价组织；代表文献须实际检索后加入。
4. 方案与离线实现：波动信息如何进入频率决策、输出采样计划是什么；交代已经编写的 Python 模拟与尚未实现的硬件部分。当前材料不足以补具体算法。
5. 评估计划：相同输入与预算下比较固定采样；分别测采样次数、任务相关的信息损失及能耗。指标和容许阈值先定义，再看结果，不能选择对自己有利的口径。
6. 局限与后续工作：模拟与真实传感器的差距、短时事件漏采风险、硬件能耗验证。

**可直接使用的提案式摘要草稿**：

> 本文研究便携水质监测中采样开销与信息保留之间的权衡，提出依据信号波动调整采样频率的方案。该方案拟利用观测到的波动信息改变采样安排，以探索减少采样次数的可能性。目前已编写 Python 离线模拟程序，尚未获得性能结果，也未开展硬件能耗测量。后续将以固定采样为基线，在明确的输入数据、预算和监测任务下，比较采样开销与信息损失，并检验采样次数变化能否转化为实际能耗收益。当前材料仅支持方案与离线实现的描述，其效果、适用范围和与已有工作的差异仍待验证。

这是研究提案/过程稿摘要，不能冒充已完成研究的结果摘要。若目标渠道要求完整实证结果，应在补齐研究后更新摘要。

**必须补的材料**：监测任务与水质变量；波动计算与频率更新规则；数据来源及事件标注；模拟程序实际行为；比较预算与基线配置；信息损失定义；传感、计算、唤醒及通信的能耗口径；重复实验与不确定性；接近工作的真实文献。无需等这些全部到齐才整理提纲，但缺项不能悄悄写成已知事实。

依据：L04-P032/P038，L05-P031/P044，L06-P035/P036；材料账本和提案式摘要为执行化整理。

## W2：流水账、过度贡献与实现矛盾

### 题面

原稿：“A用了固定周期。B用了阈值。C用了神经网络。本研究首次完美解决所有场景。设计保证每秒告警；实现每分钟批处理；现有数据仅20条脚本生成记录，无对照。”要求分类比较相关工作短段、设计实现诊断与诚实改文；A/B/C 无题录，不能编引用。

### 实际回答

最需要先改的是“每秒告警”与“每分钟批处理”的矛盾，以及“所有场景”的主张。这两处影响研究含义，先于措辞问题。

**相关工作短段草稿**：

> 已有材料涉及固定周期、阈值规则与神经网络三类机制。固定周期路线以 A 为例；规则驱动路线以 B 的阈值机制为例；模型驱动路线以 C 的神经网络为例。比较这些路线，需要统一它们所解决的任务，说明决策输入、触发或更新条件、资源开销和适用范围。当前材料只给出了机制名称，尚不足以判断哪条路线更有效，或确定本文相对它们的新意。

A/B/C 目前仅为用户代号，以上不是可直接提交的完整文献综述。原文没有说明 B 的阈值用于采样、告警还是其他环节，也没有说明 C 网络的输入输出，因此不能擅自写成“B/C 都进行自适应采样”，更不能为它们补作者、年份、题名或缺陷。取得真实来源后，应按共同问题比较，再说明本文区别。

**设计—实现—证据诊断**：

| 层次 | 当前文字 | 问题与处理 |
|---|---|---|
| 设计要求 | 每秒告警 | 含义须明确：每秒检查一次、每秒输出，还是事件发生后1秒内告警？三者不同 |
| 实际实现 | 每分钟批处理 | 若告警只在批次运行时产生，就不能据此保证任意事件1秒内告警；批次内处理耗时也未给出 |
| 验证材料 | 20条脚本生成记录，无对照 | 至多可据实际记录检查个别流程；尚不能支持准确率、时延保证、真实场景泛化或优于其他方法 |
| 总体贡献 | 首次、完美、所有场景 | 均缺相应证据；删除或收窄，不能仅换成更委婉的赞语 |

目前不能凭文字认定实现必定遗漏某个独立实时通路；如果确有该通路，应补其实现和测试。当前给出的材料没有它，因此写作只能承认现有批处理实现尚未满足/验证每秒告警的目标。

**可替换的诚实段落**：

> 本研究考察一种告警处理方案，目前实现以每分钟批处理方式运行。设计中提出的每秒告警目标尚未由现有实现和测试支持，相关时间要求仍需进一步明确。当前材料包含20条由脚本生成的记录，尚未提供对照实验及真实场景测试，因此本文暂不对告警时延、检测效果或跨场景适用性作性能结论。后续将先明确告警时间的定义，再使设计、实现和测量条件对齐，并以真实来源中的接近方法建立可比实验。

下一步有两个取舍：如果1秒内告警是核心需求，就要修实现并测端到端延迟；如果现阶段研究的是离线批处理，应相应调整研究范围与设计目标。不能同时保留实时保证和当前未证实的实现描述。

依据：L05-P044/P054，L06-P035/P036/P045/P046。

## W3：单点结果、图注与“显著更好”

### 题面

原图注：“Figure 1. Performance. Our method is significantly better.” 给定某离线 trace、N=10次，baseline 均值50 ms、ours45 ms；无方差或置信区间；横轴采样预算（个/小时），纵轴时延（ms），只测预算60这一个点。要求改图注和正文，正确表达5 ms/10%，不声称统计显著或所有预算成立。

### 实际回答

**图注**：

> 图1. 单一离线 trace 上、采样预算为60个/小时时的平均时延比较。基线与本文方法的报告均值分别为50 ms和45 ms；测试材料记录 N=10次运行，未提供离散程度或置信区间。横轴为采样预算，纵轴为时延（ms，越低越好）。

N=10究竟指每个方法各10次还是两种方法合计10次，输入没有说明；图注先保留“测试材料记录”的口径，正式成稿前应明确次数的分配、每次运行的独立性，以及两种方法是否使用相同 trace 和其他设置。不能无依据改成“each averaged over 10 independent trials”。

**正文**：

> 在该离线 trace 和60个/小时的采样预算下，本文方法的报告平均时延比基线低5 ms，即相对基线降低10%（(50−45)/50）。这一观察只描述已测条件下的均值差异。由于尚未提供方差、原始重复测量或统计分析，不能判断差异的统计显著性；单一预算点也不能支持随预算变化的趋势，或对其他 trace 的结论。该差异是否具有实际应用价值，还需结合任务的时延要求和其他代价评价。

此处将 “significantly better” 换成具体量与范围。5 ms 是绝对差，10% 是以基线50 ms为分母的相对降低，不是10个百分点。没有依据添加误差条。当前只有一个预算点，用比较两方法的点图或小表即可；若保留横轴，不应画出暗示测过中间预算的连续曲线。

依据：L06-P045/P046/P066/P102；次数口径与数值反算为执行化检查。

## W4：只润色英文，保护条件、公式和不确定性

### 题面

只改英文表达：“Our method may reduce latency when k>=2; at k=2 latency is 45 ms (baseline 50 ms). x_t = a x_{t-1}. Results are preliminary.” 要求保留公式、数值、条件及证据强度。

### 实际回答

> Our method may reduce latency when k >= 2. At k = 2, the latency is 45 ms, compared with a baseline of 50 ms. x_t = a x_{t-1}. These results are preliminary.

只将分号拆成句子、补标点与比较表达，并用 These results 明确指代。`may`、`k >= 2`、`k = 2`、`45 ms`、`50 ms`、`x_t = a x_{t-1}` 和 `preliminary` 均保留；没有推导额外性质，没有把45 ms推广到所有 k。变量与参数的定义可在正式论文首次出现处补足，但纯润色时不能猜测 a 的范围、x 的物理意义或系统稳定性。

依据：L06-P102/P103/P104，手册中的保真对照程序。

## 教学表达样例（新编，约100字）

先别把“采样更少”写成“电池更耐用”。我们沿一条输入看：波动值进入决策器，决策器输出下一次采样时间；这能说明机制怎样运行。接着要问，减少的是哪种开销，漏掉了哪些信息？先把这两项指标定义清楚，再用同条件对照检验。例子帮我们读懂流程，真实结果才决定能写多强的结论。
