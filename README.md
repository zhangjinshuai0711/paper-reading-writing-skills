# 邱寒读论文 · 元杰写论文

把《文献阅读与写作》课程中的阅读与写作方法整理成两个可以直接调用的 AI Skill，供同学在真实论文、研究记录和草稿中使用。

这是张金帅根据课程材料、借助 AI 整理的学习项目。名称沿用“邱寒读论文”和“元杰写论文”，用来识别课程方法；**不是教师或学校的官方产品，不冒充教师本人，也不承诺达到教师本人水平。**

| Skill | 调用名 | 适合做什么 |
|---|---|---|
| [邱寒读论文](.agents/skills/qiuhan-read-paper/SKILL.md) | `$qiuhan-read-paper` | 读懂核心论证、方法机制与实验证据；精读、比较、复现准备、研究评价 |
| [元杰写论文](.agents/skills/yuanjie-write-paper/SKILL.md) | `$yuanjie-write-paper` | 从真实材料建立主线，起草各章，诊断结构，修改图表、公式和语言 |

## 为什么做这两个 Skill

上课学到的不只是论文有哪些章节，更是如何判断：作者究竟解决了什么问题？一个组件为什么需要？实验支持的是哪个结论？写作时怎样让“问题—挑战—设计—证据”对应起来？

本项目把这些判断转成可以执行的步骤。第1–3讲构成阅读主干，第4–6讲构成写作主干，交叉内容按用途纳入两边。共同授课、引用外部学者及后续工程化整理均保留来源边界，不将所有方法归为某一位老师的个人原创。

本地蒸馏处理了六讲共369页课件与第2–6讲五份完整自动转写，约14.53万字符，并检查备注、关键图页和教学修改案例。**MP3内容未核听，第一讲未发现录音。** 手册保留课件页码、口述时间及歧义说明。

## 安装到 Codex

需要 Python 3 和能够加载本地 Skill 的 Codex。技能本身不需要 API Key、额外模型或 Python 依赖；Python 仅用于安装与结构检查。

先克隆仓库，或在 Releases 下载分享包并解压：

```bash
git clone https://github.com/zhangjinshuai0711/paper-reading-writing-skills.git
cd paper-reading-writing-skills
```

任选一种安装范围：

```bash
# 当前项目：替换为你自己的项目目录
python3 scripts/install.py --project /path/to/your-project

# 或安装到当前用户，供多个项目使用
python3 scripts/install.py --user
```

项目安装写入 `<项目>/.agents/skills/`，用户安装写入 `~/.agents/skills/`。安装器会在目标已存在时停止，避免覆盖你已有的技能。也可以手动复制 `.agents/skills/` 下的两个完整文件夹。

在对应项目中打开 Codex，用 `$qiuhan-read-paper` 或 `$yuanjie-write-paper` 调用。Codex通常自动发现技能变化；如果未出现，可重启。不要在项目和用户目录重复安装同名 Skill，以免选择时出现多个副本。路径与发现行为依据 [Codex官方技能文档](https://developers.openai.com/codex/skills/)。

只有网页聊天、没有本地 Skill 加载能力时，可以打开 `SKILL.md`，连同本次任务需要的参考手册提供给支持文件阅读的助手；这属于手动使用，不能视作已安装或与Codex相同的完整功能。其他客户端的技能目录及兼容性未测试。

## 使用方式

默认直接做任务；明确说“带我读／带我写”才逐步教学。请同时提供需要处理的论文全文、研究记录或草稿，不能仅凭技能名称获得未提供的论文内容。

### 读懂一篇论文

```text
请用 $qiuhan-read-paper 分析这篇论文。
先给一句话概括和完整流程，再沿一个连续例子解释各阶段的输入、操作、输出与下游使用，
最后核查实验真正支持了什么，哪些结论仍然缺证据。
```

### 定向精读或多篇比较

```text
请用 $qiuhan-read-paper 比较这三篇论文。
按同一问题、假设、方法、成本和证据比较；不同实验条件下的分数不要直接排名。
```

```text
请用 $qiuhan-read-paper 带我读这篇论文，从 Introduction 和 Methods 开始。
先讲全局，再逐步展开。我说“继续”时沿当前进度推进。
```

### 从研究记录开始写

```text
请用 $yuanjie-write-paper 把这些真实研究记录组织成论文主线、章节提纲和摘要。
先对应问题、挑战、设计和证据；实验未完成的部分明确标记，不补造结果或引用。
```

### 修改论文

```text
请用 $yuanjie-write-paper 修改这段引言和相关工作。
按问题与思想组织比较，保留所有技术含义、公式、数字和条件，并说明关键改动理由。
```

```text
请用 $yuanjie-write-paper 检查这张图和图注是否自明，起草结果分析段。
区分设置、直接观察、解释与边界，不补造误差条、显著性或趋势。
```

## 两套方法包含哪些内容

**阅读**从目标与深度选择开始，提取背景、问题、已有局限、idea、设计和验证；从架构图进入组件机制，沿toy example追踪输入输出，再核对真实条件；审查数据、实现层次、参数、指标、基线、总体效果与组件证据，最后结合领域背景评价研究价值。

**写作**从真实材料与读者开始，建立问题、挑战、设计和证据的主线；覆盖标题、摘要、引言、贡献、背景、相关工作、动机、适用时的威胁模型、概览、详细设计、实现、评估、讨论、局限、未来工作、结论、致谢与附录；并处理图表、公式、算法和保真润色。

每套包含方法手册、正反案例、六维蒸馏底稿、来源定位和验证记录。入口仅加载当前任务需要的章节，不要求每次读取全部参考资料。

## 公开版与本地完整版的区别

公开版保留运行所需的方法、案例与释义，**不发布原始课件、课堂录音、完整转写、逐页课件文字、论文截图、私人课堂笔记或课程群信息**。这些原始课程材料没有随本仓库获得公开分发授权。

因此，日常运行不依赖整理者电脑；但如果要核查某页课程原述或原图，需自行合法取得相应课程资料。分析新论文时应引用该论文的实际页、节、图或数据，课程索引不能代替新论文证据。具体见各 Skill 的 `references/source-index.md`。

## 测试与已知边界

本地完整版完成3项阅读主测试、2项课程规则补测和4项写作测试。主测试由答题角色实际执行，再由另一角色独立评审；补测另有主代理核查记录。核心行为包括纠正AI误读、避免证据外推、材料不足时继续完成可做部分，以及不编造结果、不改坏公式与数字。

这些是**历史有限场景测试**。公开版没有完整课堂证据附件，也没有重新运行同一组行为测试；本次另外检查了公开版结构、链接、安装与排除原始材料。验证记录保留在各包的 `references/validation/`。这不证明长期稳定性、真实全文复现、期刊接收率或教师水平。

本课程正式review禁止AI-generated review；写作的AI使用须遵循课程CFP。课程作业分支独立保存，不把历史日期、3页格式等套成所有研究论文的要求。使用者需遵守本次课程、单位和投稿渠道的实际规定。

可在本地运行：

```bash
python3 scripts/validate.py
```
